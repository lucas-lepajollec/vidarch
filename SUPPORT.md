# Support

Start with the [README](README.md) and the [documentation](https://docs.vidarch.lucas-homelab.fr). Search existing [GitHub issues](https://github.com/lucas-lepajollec/vidarch/issues) before opening a new report.

For a reproducible problem, use the bug form and include the VidArch commit or version, deployment method, browser, Node/Docker and `yt-dlp` versions, sanitized reproduction steps and relevant logs. Never publish cookies, account information, database contents, private URLs, downloaded media or session secrets. Use public or authorized media when a sample URL is required.

Questions already answered in the documentation or reports that cannot be reproduced may be closed. Suspected vulnerabilities must follow [SECURITY.md](SECURITY.md), not a public issue.
